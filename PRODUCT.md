# PRODUCT SPECIFICATION / TÀI LIỆU DỰ ÁN

## 1. Giới thiệu Tổng quan / Overview

- **EN:** **AI Content Workspace** is a modern web application designed for content creators. It automates keyword research, article drafting, image generation, and publishing workflows using an AI Agent system.
- **VI:** **AI Content Workspace** là nền tảng web hiện đại dành cho nhà sáng tạo nội dung, hỗ trợ tự động hóa luồng nghiên cứu từ khóa, viết bản thảo, tạo ảnh minh họa và xuất bản bài viết thông qua hệ thống AI Agent.

---

## 2. Giao diện & Trải nghiệm / Design System (UI/UX)

- **Theme & Palette:**
  - Main Background: Warm Cream / Off-White (`#FAF7F2`)
  - Accent / Highlights: Deep & Soft Purple / Violet (`#7C3AED`, `#6D28D9`)
- **Vibe:** Soft UI / Modern Minimalist – Tối giản, trang nhã, êm mắt và mượt mà.
- **Rules:** Tuân thủ quy chuẩn token của `impeccable` và nguyên tắc thiết kế phân cấp từ `ui-ux-pro-max-skill`.

---

## 3. Chức năng chính / Key Features

### 3.1. Tạo bài viết tự động / AI Article Generation

- **EN:** Input primary topic or keywords to trigger automated research and article drafting.
- **VI:** Nhập chủ đề hoặc từ khóa để khởi chạy Agent tự động nghiên cứu nội dung và lập bản thảo bài viết.

### 3.2. Theo dõi trạng thái Real-time / Real-time Agent Tracker

- **EN:** Visual progress indicators (Researching -> Writing -> Generating Images -> Publishing) with percentage status updates (e.g., 60%).
- **VI:** Widget hiển thị tiến trình xử lý trực quan từng giai đoạn của Agent kèm phần trăm hoàn thành.

### 3.3. Quản lý bài viết gần đây / Recent Articles Management

- **EN:** Clean card layout displaying draft and published articles with quick action triggers (Edit, Preview, Export).
- **VI:** Danh sách bài viết dạng thẻ (Card Layout) hiển thị bản thảo và bài đã xuất bản, hỗ trợ xem nhanh, chỉnh sửa và xuất nội dung.

---
